## Что это

P2P-мессенджер, работающий **через сеть Tor**. Каждый пользователь — **скрытый сервис** с `.onion`-адресом. Никаких центральных серверов. Никакой регистрации. Никаких метаданных.

## Возможности

### 🔐 Шифрование
- **E2E** — X25519 (Diffie-Hellman) + AES-256-GCM
- **Tor Hidden Services** — твой IP скрыт
- **Локальное хранилище** — зашифровано производным ключом

### 💬 Общение
- Личные чаты
- Групповые чаты с ролями
- Индикатор «печатает...»
- Online/offline статус
- Отметки прочтения
- Файлы до 50 MB

### 🛠 Инструменты
- Поиск по сообщениям
- Экспорт чатов (TXT / JSON)
- Backup идентичности
- Проверка fingerprint
- Блокировка контактов
- Чёрный список

## Как это работает

```
КЛИЕНТ A                          КЛИЕНТ B
   │                                  │
   ├── .onion-адрес A ──── Tor ────►  │
   │                                  │
   ├── HELLO ────────────────────────►│
   │◄─────────────────── HANDSHAKE ───┤
   │                                  │
   │  (X25519 Diffie-Hellman)         │
   │  (общий AES-ключ)                │
   │                                  │
   ├── TEXT (зашифровано) ───────────►│
   │◄──────────────────── ACK ────────┤
```

Сервер **не существует**. Каждый клиент сам является сервером.

## Установка

### 1. Скачай Tor Expert Bundle

**Windows:** https://www.torproject.org/download/tor/
- Скачай **Windows Expert Bundle**
- Распакуй в папку `tor/` внутри проекта
- Там должен быть `tor.exe`

**Linux:**
```bash
sudo apt install tor
```

**macOS:**
```bash
brew install tor
```

### 2. Установи Python-зависимости

```bash
pip install -r requirements.txt
```

### 3. Запусти

```bash
python Nocturne.py
```

При первом запуске:
1. Введи псевдоним (или оставь пустым)
2. Сгенерируется UUID + X25519 ключи
3. Tor запустится и создаст `.onion`-адрес
4. **Скопируй .onion-адрес** — передай другу

## Как начать общение

1. **Ты:** запускаешь NOCTURNE → получаешь `.onion`-адрес
2. **Друг:** тоже запускает NOCTURNE → получает свой адрес
3. **Обмен:** вы обмениваетесь `.onion`-адресами
4. **Подключение:** в NOCTURNE нажимаешь `+`, вводишь `.onion` друга
5. **Готово:** можно писать сообщения

## Управление

| Действие | Как |
|----------|-----|
| Мой ID | Меню → Файл → Мой ID |
| Добавить контакт | Кнопка `+` в левой панели |
| Создать группу | Вкладка «Группы» → `+ Группа` |
| Отправить файл | Кнопка 📎 или drag&drop |
| Поиск | Меню → Контакты → Поиск |
| Настройки | Меню → Файл → Настройки |
| Backup | Меню → Файл → Backup |
| Экспорт чата | Меню → Файл → Экспорт чата |

## Файлы данных

```
~/.nocturne/
├── identity.json      # UUID, ключи, onion-адрес
├── messages.db        # зашифрованная история
├── contacts.json      # список контактов
├── groups/            # группы
├── files/             # полученные файлы
├── blacklist.json     # чёрный список
├── settings.json      # настройки
└── message_queue.json # очередь
```

⚠️ **НЕ удаляй `identity.json`** — потеряешь доступ ко всем контактам.

## Безопасность

### Что защищено
- ✅ Содержимое сообщений — E2E AES-256-GCM
- ✅ Твой IP — скрыт через Tor
- ✅ Метаданные — Tor не знает, кто с кем общается
- ✅ Локальное хранилище — зашифровано
- ✅ Приватный ключ — никогда не покидает устройство

### Что НЕ защищено
- ⚠️ Твой псевдоним
- ⚠️ Время ответа
- ⚠️ Размер сообщений

### Рекомендации
- Используй **разные псевдонимы** для разных контактов
- **Не сообщай** личные данные
- **Обменивайся .onion** через безопасный канал
- Делай **backup идентичности**
